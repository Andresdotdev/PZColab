🧟‍♂️ PZColab

Run a free Project Zomboid dedicated server on Google Colab — no VPS, no port forwarding, no credit card.

Open in Google Colab ▶

Why PZColab?

  • Zero infrastructure cost — the server runs on Colab's free tier.
  • Works on Build 42 (stable) and Build 41 (legacy) — pick the version at install.
  • Automatic installation with SteamCMD and 6 GB memory tuning for Colab.
  • Persistent worlds — saves and configs live on your Google Drive.
  • Easy mods — paste Workshop URLs or whole Steam collections; the notebook detects each mod's real ID automatically.
  • Public address via the built-in Playit.gg tunnel — friends join in seconds.
  • Crash watchdog, clean shutdown, live console, saves backup and log diagnostics.

Quick start

  1. Open PZ_Colab_EN.ipynb in Google Colab (button above).
  2. Run Cell 1 — choose the game version, installs the server and mounts Drive.
  3. Run Cell 2 — claim your persistent Playit.gg tunnel (first time only).
  4. Run Cell 3 — the server starts; share the IP/port Playit assigns you.
